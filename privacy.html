Политика конфиденциальности приложения «АЮЛ»

Приложение «АЮЛ» предназначено для просмотра новостей, информации о мероприятиях и обучающих программах молодёжной некоммерческой организации АЮЛ, а также для участия в личном кабинете: прохождения квизов, получения сертификатов участника, обмена контактами между участниками и обсуждения новостей в комментариях.

1. Личный кабинет и регистрация

Для использования личного кабинета пользователь создаёт учётную запись по электронной почте и паролю через Firebase Authentication. При регистрации и заполнении профиля пользователь может указать: имя, электронную почту, номер телефона, а также сведения об участии в мероприятиях организации.

При регистрации пользователь также обязательно принимает условия использования приложения, включая правила размещения комментариев и порядок модерации контента. Ознакомиться с условиями использования можно на экране регистрации до создания учётной записи.

Пароль хранится и обрабатывается сервисом Firebase Authentication (Google) в зашифрованном виде — приложение не имеет доступа к паролю пользователя в открытом виде.

2. Публичный профиль, достижения и сертификаты

В личном кабинете формируется публичный профиль участника: имя, значки достижений и история участия в мероприятиях. Эти данные могут быть видны другим участникам приложения.

При завершении участия в мероприятии пользователь может запросить именной сертификат. Заявка на сертификат (имя участника, название и дата мероприятия) сохраняется в базе данных и становится доступна администратору для подтверждения. После одобрения сертификат с именем участника и названием мероприятия формируется приложением и может быть сохранён или отправлен пользователем самостоятельно (функция «Поделиться»).

3. Комментарии к новостям, жалобы и блокировка пользователей

Под новостями и анонсами мероприятий участники, вошедшие в личный кабинет, могут оставлять комментарии. Комментарий публикуется вместе с именем автора, указанным в профиле, и виден всем пользователям приложения, включая тех, кто не входил в личный кабинет.

Автор может в любой момент удалить собственный комментарий самостоятельно. Любой пользователь может пожаловаться на комментарий, нарушающий правила использования приложения — при этом текст комментария, а также идентификаторы автора жалобы и автора комментария направляются администраторам приложения для проверки. По результатам проверки администратор вправе удалить нарушающий правила комментарий и, при необходимости, заблокировать учётную запись его автора (см. раздел 8).

Помимо жалобы, пользователь может самостоятельно заблокировать автора конкретного комментария — после этого комментарии заблокированного пользователя перестают отображаться лично для вас в приложении. Список заблокированных вами пользователей доступен в личном кабинете, где блокировку можно снять в любой момент. Такая блокировка не влияет на видимость комментариев для других пользователей.

4. Обмен контактами между участниками

Участники могут отправлять друг другу запрос на обмен контактными данными. После того как получатель запроса подтверждает его, отправителю становятся видны номер телефона и адрес электронной почты получателя, указанные им в профиле. Без подтверждения получателя эти данные другим пользователям не передаются.

5. Использование сервисов Firebase

Для работы приложения используются облачные сервисы Firebase (Google Cloud):

  • Firebase Authentication — для регистрации и входа в личный кабинет.
  • Cloud Firestore — для хранения новостей, данных о мероприятиях, профилей участников, заявок на сертификаты, заявок на обмен контактами, комментариев к новостям, жалоб на комментарии, а также списков заблокированных пользователями пользователей и статуса блокировки учётной записи администратором.
  • Cloud Storage — для хранения и отображения медиафайлов (изображений).
  • Firebase Cloud Messaging — для отправки push-уведомлений (см. раздел 6).
  • Firebase Analytics — для сбора обезличенной статистики использования приложения.
  • Cloud Functions — для выполнения операций, требующих расширенных прав: полного удаления учётной записи (см. раздел 9) и блокировки/разблокировки учётной записи администратором при нарушении правил использования приложения.

При взаимодействии приложения с серверами Firebase технически передаётся стандартная информация, необходимая для установления соединения, включая IP-адрес устройства. Эти данные обрабатываются компанией Google в соответствии с её политикой конфиденциальности.

Приложение использует Firebase Analytics для сбора обезличенной статистики использования: какие разделы приложения открывают, как часто проходят квиз, запрашивают сертификаты и другие подобные события. Эти данные используются исключительно для развития и улучшения приложения. Приложение не использует рекламные идентификаторы, не показывает персонализированную рекламу и не передаёт данные аналитики третьим лицам в рекламных целях.

6. Push-уведомления

Приложение отправляет push-уведомления (например, о новых мероприятиях и напоминания о них) через Firebase Cloud Messaging. Для этого на сервере сохраняется технический идентификатор устройства (device token), который используется исключительно для доставки уведомлений и не связывается с рекламными или аналитическими профилями. Уведомления можно отключить в настройках устройства.

7. Обратная связь

Если пользователь самостоятельно обращается в службу поддержки по электронной почте, предоставленные им контактные данные используются исключительно для ответа на обращение и решения указанной проблемы. Мы не используем эти данные для рассылок.

8. Модерация и блокировка учётных записей администратором

Мы не терпим оскорбительный, незаконный или иным образом недопустимый контент и поведение пользователей. Жалобы на комментарии рассматриваются администраторами, как правило, в течение 24 часов. Если комментарий или поведение пользователя нарушает правила использования приложения, администратор вправе удалить комментарий и заблокировать учётную запись нарушителя.

Заблокированная администратором учётная запись полностью теряет доступ к приложению до момента снятия блокировки. Сведения о том, что учётная запись заблокирована, и о том, каким администратором она была заблокирована, сохраняются в Cloud Firestore на время действия блокировки и удаляются при её снятии.

9. Хранение и удаление данных

Данные личного кабинета (профиль, история участия, заявки на сертификаты и контакты) хранятся, пока учётная запись пользователя активна. Пользователь может самостоятельно удалить свою учётную запись и все связанные с ней данные (профиль, история участия, заявки на сертификаты и обмен контактами, фото профиля) в любой момент — в приложении, в разделе «Профиль» → «Удалить аккаунт». Удаление происходит безвозвратно и не может быть отменено. При необходимости также можно обратиться по адресу, указанному в разделе «Контакты».

Комментарии, оставленные участником под новостями, можно удалить в любой момент самостоятельно — непосредственно в списке комментариев под соответствующей новостью.

Список пользователей, заблокированных вами лично, хранится вместе с профилем и удаляется при удалении учётной записи; в любой момент отдельных пользователей из этого списка можно разблокировать вручную в личном кабинете.

10. Изменения в Политике конфиденциальности

Мы можем обновлять настоящую Политику конфиденциальности. Актуальная версия документа всегда доступна по этому адресу.

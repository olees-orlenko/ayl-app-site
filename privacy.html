Политика конфиденциальности приложения «АЮЛ»

Приложение «АЮЛ» предназначено для просмотра новостей, информации о мероприятиях и обучающих программах молодёжной некоммерческой организации АЮЛ.

1. Сбор и использование данных

Мы не требуем от пользователей создания учётной записи и не собираем персональные данные, такие как имя, фамилия, номер телефона, адрес электронной почты или данные о местоположении.

Приложение не использует рекламные идентификаторы, не содержит персонализированной рекламы и не отслеживает действия пользователей в рекламных или аналитических целях.

2. Использование сервисов Firebase

Для корректной работы приложения (загрузки новостей, текстов, изображений и расписаний) мы используем облачные сервисы Firebase (Google Cloud), а именно:

  • Cloud Firestore — для хранения и получения текстовой информации и данных о мероприятиях.
  • Cloud Storage — для хранения и отображения медиафайлов (изображений).

При взаимодействии приложения с серверами Firebase технически передается стандартная информация, необходимая для установления соединения, включая IP-адрес устройства. Данные параметры обрабатываются компанией Google в соответствии с их политикой конфиденциальности. Мы не используем эту информацию для идентификации пользователей или создания их профилей.

3. Уведомления

Приложение не отправляет push-уведомления и не запрашивает у пользователя разрешений на их получение.

4. Обратная связь

Если пользователь самостоятельно обращается в службу поддержки по электронной почте, предоставленные им контактные данные используются исключительно для ответа на обращение и решения указанной проблемы. Мы не храним эти данные в базе приложения и не используем их для рассылок.

5. Изменения в Политике конфиденциальности

Мы можем обновлять настоящую Политику конфиденциальности. Актуальная версия документа всегда доступна по этому адресу.
